# Demo corpus provenance

All documents in this directory were created specifically for Visual Scan.
They are synthetic fixtures intended to exercise the application's document
intake, OCR, analysis, and archive flows.

- No real documents, personal data, banking data, addresses, telephone
  numbers, signatures, or organization logos were used.
- All people, organizations, identifiers, dates, transactions, and amounts are
  fictional and fixed.
- Any domain shown in a document uses `example.com`.
- No external photographs, illustrations, logos, or signatures are embedded.
- The accompanying UTF-8 text files are the authoritative source content for
  each document. They are not promises of exact OCR output.
- The repository currently has no project-wide license. This corpus therefore
  does not assign itself a separate license implicitly.

The images and image-only PDF were rendered from text and simple geometric
shapes. The receipt compression, contract skew, and low-contrast note are
deliberate synthetic degradations.
